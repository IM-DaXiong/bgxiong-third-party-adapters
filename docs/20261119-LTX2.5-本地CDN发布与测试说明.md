### 你需要做的最后一步（签名 → 上传变更文件）

本机私钥在 `%USERPROFILE%\.tauri\bgxiong-adapter-index`。签名密码只能在你自己的交互终端输入，智能体不能代签。

任意目录直接粘贴执行：

```powershell
Set-Location 'L:\00Dev\bgxiong-third-party-adapters'; powershell -NoProfile -ExecutionPolicy Bypass -File 'L:\00Dev\bgxiong-third-party-adapters\scripts\sign-online-index-interactive.ps1' -RequireNewInstall local.bgx.ltx25@0.1.3
```

签完后不必重传整个 CDN 目录，另外 ZIP 都没变。只传这 3 个文件：

1. 先传 `L:\00Dev\bgxiong-third-party-adapters\artifacts\cdn\local.bgx.ltx25-0.1.3.zip`
2. 再传 `L:\00Dev\bgxiong-third-party-adapters\artifacts\cdn\SHA256SUMS.txt`
3. 最后覆盖 `L:\00Dev\bgxiong-third-party-adapters\artifacts\cdn\latest.json`

如果觉得逐个选麻烦，直接拖整个 `L:\00Dev\bgxiong-third-party-adapters\artifacts\cdn\` 覆盖也可以，效果一样。公网回读验签通过后，再跑：

```powershell
Set-Location 'L:\00Dev\bgxiong-third-party-adapters'; python 'L:\00Dev\bgxiong-third-party-adapters\scripts\publish-online-index.py' --commit-receipt --pubkey "$env:USERPROFILE\.tauri\bgxiong-adapter-index.pub"
```

若只想先换包、暂不改索引：也可先只上传 `artifacts\cdn\local.bgx.ltx25-0.1.3.zip`；软件「在线安装/检查更新」仍要等签过的 `latest.json`。开发版 exe 也可直接选本地目录 `L:\00Dev\bgxiong-third-party-adapters\artifacts\current\local.bgx.ltx25\0.1.3\` 安装测试。
