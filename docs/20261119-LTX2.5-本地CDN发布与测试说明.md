### 你需要做的最后一步（签名 → 上传目录）

本机私钥在 `%USERPROFILE%\.tauri\bgxiong-adapter-index`。签名密码只能在你自己的交互终端输入，智能体不能代签。

在适配器仓根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\sign-online-index-interactive.ps1 -RequireNewInstall local.bgx.ltx25@0.1.1
```

成功后拖走整目录上传：

`L:\00Dev\bgxiong-third-party-adapters\artifacts\cdn\`

其中应含 `latest.json`、全部当前 ZIP（含 `local.bgx.ltx25-0.1.1.zip`）和 `SHA256SUMS.txt`。  
先上传 ZIP，再切换正式 `latest.json`，公网回读验签通过后，再跑：

```powershell
python .\scripts\publish-online-index.py --commit-receipt --pubkey "$env:USERPROFILE\.tauri\bgxiong-adapter-index.pub"
```

若只想先换包、暂不改索引：也可先只上传 `artifacts\cdn\local.bgx.ltx25-0.1.1.zip`；软件「在线安装/检查更新」仍要等签过的 `latest.json`。
