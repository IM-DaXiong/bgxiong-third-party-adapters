# Seedance 2.5

适配包使用火山方舟 `doubao-seedance-2-5-260628`。安装时绑定方舟 API Key。提交、原任务查询和取消使用方舟 API 来源，成片及尾帧通过 SDK 授权的成果来源下载。

- 文生视频、首帧和首尾帧各有独立操作。首尾帧分别接收原图。
- 全模态参考接收图片、音频以及视频地址。编辑和延长至少需要一条参考视频地址。
- 在「参考视频地址或素材 ID」中逐行填写公开 HTTPS 视频地址或 `asset://` 素材 ID。私有视频先通过有权限的渠道登记为方舟素材。内嵌 Base64 视频无法通过方舟的请求校验，适配包在提交前校验此字段。
- 启用「返回尾帧」后，SDK 保留方舟返回的可用尾帧原件和视频原件。

[火山方舟创建视频生成任务](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)
