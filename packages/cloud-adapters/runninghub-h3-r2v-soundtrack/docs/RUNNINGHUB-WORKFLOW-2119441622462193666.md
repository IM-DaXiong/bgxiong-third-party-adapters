## 提交

`POST https://www.runninghub.cn/openapi/v2/run/workflow/2119441622462193666`

官方示例：

```json
{
  "addMetadata": true,
  "nodeInfoList": [],
  "instanceType": "default",
  "usePersonalQueue": "false"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `addMetadata` | Boolean | 可选 | 输出中写入工作流元数据 |
| `nodeInfoList` | List | 必填 | 节点参数映射，动态修改已有节点字段 |
| `instanceType` | String | 可选 | `default`（24G）/ `plus`（48G）/ `ultra`（84G） |

| `webhookUrl` | String | 可选 | 完成时 POST 回调 |

提交响应：`taskId`、`status`（`QUEUED` / `RUNNING` / `SUCCESS` / `FAILED`）、`errorCode`、`errorMessage`、`results`（提交时为 null）、`clientId`、`promptTips`（ComfyUI 校验信息 JSON 字符串）。

### 本包的实际请求体

每次按用户的 1～9 张参考图和恰好 1 段原声重建整图：删烘焙的 LoadImage/LoadAudio，插入 `1000+n` 与 `2000`，`2000` 同时接到 136 和 130，SaveVideo 92 改为 9000。空的 `nodeInfoList` 不能增减素材节点，所以本包比官方示例多一个 `workflow` 整图字符串。

```json
{
  "workflow": "<改写后的整图 JSON 字符串>",
  "nodeInfoList": [],
  "addMetadata": true,
  "instanceType": "<配置值>",
  "usePersonalQueue": false
}
```

- `usePersonalQueue` 按参数表的 Boolean 发 `false`，不跟示例里的字符串。
- 不发 `webhookUrl`、`retainSeconds`。

## 查询

`POST https://www.runninghub.cn/openapi/v2/query`，body `{"taskId":"..."}`。

响应字段：`taskId`、`status`、`results[]`（`url` / `nodeId` / `outputType` / `text`）、`errorCode`、`errorMessage`、`failedReason`、`usage`（`consumeMoney`、`consumeCoins`、`taskCostTime`、`thirdPartyConsumeMoney`）。

结果 `url` 只保留 24 小时。本包在任务成功后立即经受管下载取回原片；下载失败保留原任务号续查，不重新生成。

官方示例里的 `nodeId: "2"`、`outputType: "png"` 是平台通用图片样例，不是本工作流的输出合同。本包只认单条结果且 `nodeId == "9000"`。

## 上传

`POST https://www.runninghub.cn/openapi/v2/media/upload/binary`，multipart 字段 `file`。

响应 `data.fileName` 写入 LoadImage / LoadAudio，不用 `download_url`。上传链接有效期 1 天。
