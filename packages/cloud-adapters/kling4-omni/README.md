# 可灵 4.0 Omni

SDK 2.1.4 适配器候选。支持显式的文生视频和 1 至 10 张有序参考图。时长 3–30 秒，清晰度 720p 或 1080p。创建请求使用北京 API，素材按 SDK 受管句柄读写。

- 安装候选目录含 package、adapter-install.json 和 LICENSE。通过「设置 → 第三方适配器 → 安装适配包」选择该目录，并在产品凭据表单录入可灵 API Key。
- 适配器保存原任务号供查询和成果回收。云端未确认受理时请核对原任务。
- 视频参考、编辑、首尾帧及音色接线仍在后续阶段。正式发行以真实账户和成果回收验收为准。

开发复验使用本批 SDK 的 CLI/worker 执行 Build.ps1。包内原生测试运行 cargo test --locked --offline --lib。测试使用合成请求和媒体。
