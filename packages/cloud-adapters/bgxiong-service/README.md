# 比格熊语音识别

在「设置 → 第三方适配器」选择包含 adapter-install.json 的目录。适配器将随包声明的语音转写能力加入导演台。F1 和文本工作台可选择「比格熊语音识别」，在录音前确认每小时积分和本次上限。

适配器使用导演台宿主注入的短期任务授权。登录与充值使用用户的比格熊账号。当前包需要宿主已支持 speech.transcribe v1 和比格熊语音服务接线。

0.1.2 开发包同时声明 speech.subtitle v1，需要包含该操作注册的 SDK。配套工作站可从 Resolve 插件接收字幕任务，按含静音的原始时长报价和扣费，并使用云端返回的原始样本时间生成字幕。

在独立开发环境连接本机的联调服务时，价目与执行需使用同一云端基址。联调服务只认登记样本。
