## 提交

`POST https://www.runninghub.cn/openapi/v2/run/workflow/2119436868289912833`

官方示例：

```json
{
  "addMetadata": true,
  "nodeInfoList": [],
  "instanceType": "default",
  "usePersonalQueue": "false"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `addMetadata` | Boolean | 可选 | 输出中写入工作流元数据 |
| `nodeInfoList` | List | 必填 | 节点参数映射，动态修改已有节点字段 |
| `instanceType` | String | 可选 | `default`（24G）/ `plus`（48G）/ `ultra`（84G） |
| `usePersonalQueue` | Boolean | 可选 | 个人独占队列 |
| `retainSeconds` | Integer | 可选 | 10～180 秒实例保留；仅企业共享 Key 生效，按保留时长额外计费 |
| `webhookUrl` | String | 可选 | 完成时 POST 回调 |

提交响应：`taskId`、`status`（`QUEUED` / `RUNNING` / `SUCCESS` / `FAILED`）、`errorCode`、`errorMessage`、`results`（提交时为 null）、`clientId`、`promptTips`（ComfyUI 校验信息 JSON 字符串）。

### 本包的实际请求体

本包是多参包：每次按用户的 1～9 张参考图和 0～3 段参考音重建整图（删烘焙的 LoadImage/LoadAudio，插入 `1000+n` / `2000+n` 并接到 136，SaveVideo 92 改为 9000）。空的 `nodeInfoList` 只能改云端烘焙图里已有的字段，做不到增减素材节点，所以本包比官方示例多一个字段：

```json
{
  "workflow": "<改写后的整图 JSON 字符串>",
  "nodeInfoList": [],
  "addMetadata": true,
  "instanceType": "<配置值>",
  "usePersonalQueue": false
}
```

- `usePersonalQueue` 按参数表的 Boolean 发 `false`，不跟示例里的字符串。
- 不发 `webhookUrl`、`retainSeconds`。
- 与同族 Turbo（`2100758868111486978`）、Spectrum（`2116576147646533634`）动态包的提交方式相同。

## 查询

`POST https://www.runninghub.cn/openapi/v2/query`，body `{"taskId":"..."}`。

响应字段：`taskId`、`status`、`results[]`（`url` / `nodeId` / `outputType` / `text`）、`errorCode`、`errorMessage`、`failedReason`、`usage`（`consumeMoney` 运行时长金额、`consumeCoins` RH 币、`taskCostTime` 运行耗时、`thirdPartyConsumeMoney` 三方 API 金额）。

结果 `url` 只保留 24 小时，过期永久失效。本包在任务成功后立即经受管下载取回原片；下载失败保留原任务号续查，不重新生成。

官方示例里的 `nodeId: "2"`、`outputType: "png"` 是平台通用图片样例，不是本工作流的输出合同。本包只认单条结果且 `nodeId == "9000"`；云端若忽略 `workflow` 而跑烘焙图（输出节点 92），显式失败，不把旧图结果当成功。视频格式以 SDK 受管探测的 `video/*` 为准，不按 `outputType` 猜。

## 上传

资源参数可以是公开 URL 或 Base64 Data URI。本包使用 RH 上传接口：

`POST https://www.runninghub.cn/openapi/v2/media/upload/binary`，multipart 字段 `file`。

响应 `{"code":0,"message":"success","data":{"type":"image","download_url":"...","fileName":"openapi/xxxx.png","size":"3490"}}`。本包写入 LoadImage / LoadAudio 的是 `data.fileName`（Comfy 相对名），不用 `download_url`。上传链接有效期 1 天。
